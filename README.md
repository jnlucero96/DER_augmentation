# DER_augmentation
Repository for analysis scripts and data of: 

"A Microgrid Deployment Framework to Support Drayage Electrification"

The electrification of heavy-duty commercial vehicles (HDCVs) is key to reducing emissions and urban air pollution, but it also imposes significant demands on an electric grid not designed for such high loads. Without complementary infrastructure, electrification may yield limited emissions reductions. This paper explores the critical role of microgrids—integrating solar photovoltaics and battery storage—in supporting HDCV electrification. We present an integrated framework to identify viable microgrid sites in a given region, estimate deployment costs, and optimize power use to reduce dependence on existing grid infrastructure. As a case study, we apply the framework to the region around the Port of Savannah, GA, USA, demonstrating how targeted microgrid deployment can enhance grid capacity, improve energy resiliency, and support low-emissions freight transport.

# Usage Instructions

Run the 'site_specific_optimization.m' script in the src to generate the results for the analysis presented in Supplemental Information - Section 6. Run all the cells in the 'process_sites.ipynb' of the data/results/site_specific directory to generate the processed data file from the Summary Data files and then run 'suppl_sec6.ipynb' to generate the Supplemental Information - Section 6 results.

Run the 'site_varied_optimization.m' script in the src directory with 'ell_scaling_factor = 1.0;' to generate the results for the aggressive electrification scenario. Move all excel files generated from data/results/site_varied to the subfolder data/results/site_varied/800kWh_fullElectrification and run the 'process_sites.ipynb' jupyter notebook in that directory to generate the processed data file. Then run the 'site_varied_optimization.m' script in the src directory with 'ell_scaling_factor = 801/(848 + 460 + 801);' to generate the results for the VMT-based electrification scenario. Move all excel files generated from data/results/site_varied to the subfolder data/results/site_varied/800kWh_VMTElectrification and run the 'process_sites.ipynb' jupyter notebook to generate the processed data file. Then run 'process_sites.ipynb' in that same directory to generate the process data file. Following this, run the 'main_text.ipynb' notebook in the src directory to generate the plots found in the main text of the paper.
